# My Blog

A Jekyll blog hosted on GitHub Pages. Posts live in `_posts/`.

## Adding a new post

Create a file in `_posts/` named `YYYY-MM-DD-short-title.md` with front matter like:

```yaml
---
layout: post
title: "Post Title"
date: YYYY-MM-DD
categories: some tags
---
```

Then write the post content below the front matter in Markdown, commit, and push. GitHub Pages rebuilds the site automatically.
